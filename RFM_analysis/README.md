# RFM-анализ клиентской базы интернет-магазина

Сегментация клиентов британского интернет-магазина через RFM-анализ на основе датасета *Online Retail*.

## Цель исследования

Изучить клиентскую базу магазина через историю покупок, провести сегментацию покупателей и определить, какие сегменты наиболее ценны для бизнеса, сделать выводы исходя из результатов RFM-анализа.

## Данные

- **Источник**: [Online Retail - Kaggle Online Retail](https://www.kaggle.com/datasets/tunguz/online-retail)
- **Период**: декабрь 2010 - декабрь 2011
- **Объём**: 541 910 строк, 8 столбцов (номер транзакции, код и описание товара, количество, дата, цена, ID клиента, страна)

## Предобработка данных

- Приведение даты к типу *datetime*
- Удаление строк без *Customer ID*
- Удаление отменённых заказов (транзакции *Invoice*, начинающиеся на "C")
- Удаление строк с отрицательным количеством или ценой
- Удаление дубликатов строк
- Проверка выбросов по количеству и цене — крупные значения оставлены в выборке, так как определены как оптовые продажи, а не аномалии данных. Влияние данных выбросов на общий итог не особо значителен

## Методология RFM

Для каждого клиента рассчитаны три метрики:

- **Recency** - сколько дней прошло с последней покупки
- **Frequency** - количество покупок у клиента
- **Monetary** - сумма покупок за всё время

Каждая метрика оценивается по 5-бальной шкале с помощью разбиения (`pd.qcut`). Для Frequency, где много повторяющихся значений, пришлось использовать ранжирование по порядку (`rank(method="first")`), так как `qcut` требует уникальности значений.

Итоговый *RFM-score* составлен на основе комбинации Recency- и Frequency-оценок клиенты распределены по 10 именованным сегментам (Champions, Loyal Customers, At Risk, Hibernating и т.д.) - для этого был использован словарь регулярных выражений.

## Основные результаты

| Сегмент | % выручки | % клиентов | Комментарий |
|---|---|---|---|
| Champions | 48% | 14,5% | Основа выручки бизнеса, главный приоритет - удержание |
| Loyal Customers | 26% | 19% | Вместе с Champions - 75% всей выручки |
| At Risk | - | 14% (597 чел.) | Не покупали ~5 месяцев, но средний чек выше 1000 - приоритет для реактивации |
| Can't Loose | - | 65 чел. | Высокая частота покупок, но Recency 129 дней - также приоритет для реактивация |
| Hibernating | 5,8% | 25% | Последняя покупка в среднем 215 дней назад - не приоритет для бизнеса - обычно привлечение обратно будет стоить дороже удержания |
| New Customers / Promising | <1% | 42 и 93 чел. | Новые клиенты, важно выстроить нормальный онбординг для дальнейшего перевода в сегмент Loyal и Champions |

## Выводы

Бизнес держится на относительно небольшом группе лояльных клиентов: сегменты Champions и Loyal Customers - треть клиентской базы, но почти 75% выручки. Наибольшую отдачу от маркетинговых усилий стоит ожидать от удержания этих двух сегментов, точечной реактивации Can't Loose и более массовой, но недорогой реактивации At Risk. Сегмент Hibernating (четверть базы) при этом даёт слишком малый вклад в выручку, чтобы оправдывать затраты на его возврат.

## Инструменты

Python, pandas, numpy, matplotlib, seaborn, scipy, squarify (для treemap-визуализации сегментов)

## Как воспроизвести

1. Скачай датасет [Online Retail с UCI](https://archive.ics.uci.edu/dataset/352/online+retail) и положи файл в папку `data/online_retail.csv`
2. Установи зависимости: `pip install pandas numpy matplotlib seaborn scipy squarify`
3. Открой `RFM-analys.ipynb` в Jupyter и выполни все ячейки по порядку
